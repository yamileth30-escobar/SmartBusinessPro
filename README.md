# 🎯SmartBusinessPro
Sistema desarrollado en C# para el control de vencimiento de productos en SmartBusinessPro. El proyecto utiliza la clase DateTime para registrar fechas de ingreso y vencimiento, identificar productos vencidos, detectar productos próximos a vencer en los siguientes 30 días, calcular días restantes y días de almacenamiento, además de aplicar validaciones y formatos de fecha.
